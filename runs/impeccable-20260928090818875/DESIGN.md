# Folio design

An editorial research workspace for professionals: deep evergreen navigation, warm paper, a quiet typographic welcome, and restrained olive interaction states. Operate mode governs controls and navigation; Read mode governs assistant responses. The distinctive folded-line F is authored SVG geometry. No external assets or services.

Tokens: paper #faf9f5; ink #293d35; sidebar #203c32; action #345b41; accent #dbe6c5; line #dedfd5. Arial/Helvetica system sans for controls and response text; Georgia for the wordmark, welcome, and response title; Menlo/Consolas for code. Desktop sidebar 264px; reading region 760px; mobile navigation below 700px. Controls have focus, hover, disabled, working, and recovery states. Motion is limited to the live activity signal, disabled for reduced motion.

The welcome provides three fixture suggestions that fill the composer. A persistent composer supports local attachments and documents limits. Tool activity remains readable inline above the latest answer. Stop retains hook-owned partial content; retry uses the same assistant message. A native mobile dialog provides modal focus management and Escape dismissal. Markdown tables and code scroll within their reading column.
