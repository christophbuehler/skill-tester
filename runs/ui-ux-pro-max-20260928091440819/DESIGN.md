# Folio

A quiet research workspace: forest-ink navigation, warm paper, muted botanical accents, and a Georgia editorial headline paired with system sans-serif UI. The asymmetry gives conversations a stable home and the research a generous reading measure. A compact composer remains available while messages scroll.

Applied ui-ux-pro-max: conversational UI guidance, visible streaming/activity states, document context cards, contrast, focus, keyboard semantics, responsive layout, reduced motion, and accessible verification. The initial design-system result's portfolio pattern was off-topic; a narrower AI chatbot SaaS search returned the applicable AI-Native UI style. Its landing-page sections are not applicable to this app. Palette recommendations were adapted to the professional editorial direction.

Brief precedence: remote font recommendations are replaced with local system fonts. Design-system persistence outside allowed files was not used; this note records the decisions instead. No packages, external assets, network services, or additional skills were introduced. Conversation, message, file, validation, and agent states belong solely to the supplied hook. Files are never read or transmitted by the interface. Markdown HTML is disabled.
