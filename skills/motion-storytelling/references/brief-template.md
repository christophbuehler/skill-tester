# Model-independent motion brief

Use this template when preparing an animated explanation. Replace the brackets and remove sections that are outside the request. It is a brief for any capable creation tool or team, not a model-specific system prompt.

## Purpose

Explain [TOPIC] to [AUDIENCE] through one coherent visual story. By the end, the viewer should understand [CENTRAL CAUSAL IDEA]. Preserve [IMPORTANT ACCURACY CONSTRAINTS]. Target [DURATION; 75–90 seconds if suitable] and [DELIVERY FORMAT].

## Visual language

Use [STYLE / EXISTING BRAND] with consistent typography, palette, material, depth and camera rules. Define stable identities for recurring objects. Include [OPTIONAL GUIDE CHARACTER] only if it improves comprehension; keep its proportions and behavior consistent. Do not add model/provider branding unless requested.

## Story and motion

Build a progression from a relatable starting point through a meaningful change and its mechanism to a consequence and a concise recap. Let the subject determine the scene count.

For each scene, supply:

- Timestamp range and learning purpose.
- Composition, objects, labels and camera.
- Main action and secondary response.
- Final voiceover, if requested, with time for pauses and visual inspection.
- Sound cue, if useful and in scope.
- The visual relationship carried into the next scene.

Give every transition a reason. Favor continuity through a retained object or meaningful transformation. Use cuts deliberately when continuity would confuse. Keep one dominant idea per shot and allow it to register before introducing the next.

## Delivery and review

Deliver [PLAN / WORKING INTERACTIVE PIECE / RENDERED VIDEO], with the relevant editable source, storyboard, narration, caption track and export instructions. A video default is 1920 × 1080 at 24 fps when no other format is specified. Review the complete sequence, check accuracy and timing, and report exactly what was rendered and inspected.

## Optional preset: handcrafted miniature

Use only when tactile, playful educational animation fits the brief:

- Paper-cut shapes, dry gouache, crayon or pencil texture; soft shallow shadows suggest a small physical stage.
- A restrained palette drawn from coral, mustard, teal, cream and charcoal, adapted to readability and the subject.
- Optional subtle handmade edge variation rather than perpetual movement on every object. Keep labels stable; remove decorative jitter in reduced-motion interactive variants.
- An optional original geometric guide with a stable silhouette, simple eyes and consistent scale. It is a narrative role, not a replica of a provider's mascot.
- Frame the composition as a miniature stage if useful. A dark terminal border is optional and inappropriate when it conflicts with the product's light visual system.

This preset should never override a user's preference for a white canvas, neutral surfaces or quiet product UI.
